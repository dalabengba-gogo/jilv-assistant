# 模板阈值表（2026-10-19 v4.9.0）
#
# 作用：给单个模板单独设一个"算命中"的相似度门槛，不用去动全局的 match_threshold。
# 为什么需要：不同模板差别很大 —— 纯文字/单色按钮往往要 0.90 才算真命中，
#   而带动态角标、半透明底的模板天生只能到 0.72～0.78；全局一刀切的结果是
#   "调高了某些步骤永远不认、调低了某些步骤乱认"。
#
# 格式：一行一条，模板名 = 阈值（0～1），# 之后是注释。写错的行会被跳过，
#   不会导致模板库加载失败（但会在 check_refs 里被点名，见下）。
#
# 优先级（从高到低）：
#   ① 脚本里某一步显式写的 threshold: 0.92
#   ② 本文件里该模板的默认值
#   ③ config.yaml → recognition.match_threshold（全局兜底）
#
# 用法示例（去掉行首 # 即生效）：
#   帮派-捐献按钮 = 0.88
#   menu_panel_back = 0.86
#
# 改完跑一遍：runtime\python.exe scripts\check_refs.py
#   它会检查这里的模板名是否真的存在、阈值是否在 0～1 之间 —— 防止手写错字
#   之后"设了却从来没生效"（最坑的一种情况：看起来配了，实际一直是全局值）。
#
# 当前没有单独配置任何模板 —— 全部使用全局 match_threshold。
